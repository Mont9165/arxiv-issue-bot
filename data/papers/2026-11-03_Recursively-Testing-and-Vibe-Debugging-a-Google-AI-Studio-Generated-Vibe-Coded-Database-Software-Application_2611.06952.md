# Recursively Testing and Vibe Debugging a Google AI Studio Generated Vibe-Coded Database Software Application

- arXiv ID: `2611.06952v1`
- Authors: Christian Mancas, Cristina Mancas
- Published: 2026-11-03
- Primary category: `cs.DB`
- Categories: `cs.DB`, `cs.SE`
- Links: [abs](http://arxiv.org/abs/2611.06952v1) | [pdf](https://arxiv.org/pdf/2611.06952v1)

## Abstract

This research paper proposes a broader definition of vibe coding, extending the original one with non-developers and natural languages other than English, and introduces the notion of vibe debugging, as well as a sound, complete, and optimal algorithmic methodology for testing and vibe debugging vibe-coded software applications. This methodology is illustrated by applying it to a vibe-coded real-world database application of medium complexity generated with Google AI Studio Pro. We prove that even non-developers can obtain a final bug-free and functional satisfactory application version, even in languages other than English. We also prove that, although Google AI Studio Pro has sophisticated built-in engines for both language analysis, software development, and automated testing, it is still making lot of mistakes, so testing and vibe debugging of its generated code is a must.
