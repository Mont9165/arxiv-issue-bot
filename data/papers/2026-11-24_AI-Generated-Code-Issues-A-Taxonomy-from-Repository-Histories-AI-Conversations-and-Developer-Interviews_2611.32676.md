## Abstract

Large language models (LLMs) are increasingly used to generate source code, yet the quality issues in such code remain only partially understood. Understanding these issues can help developers adapt quality assurance practices, such as code review and testing, to better detect problems that may be more common in AI-generated than in human-written code. We study how quality issues in AI-generated code manifest in real software development activities through a mixed-method empirical study that draws on evidence from three complementary sources. First, we mine GitHub commits whose messages explicitly attribute a fix to a problem in AI-generated code, and we manually inspect the 914 matched commits to remove false positives and classify the quality issue being corrected. Second, we collect developers' shared conversations with AI tools, identify conversations including source code and textual signals of model mistakes, and manually analyze 299 of them to classify the underlying quality issue. Third, we interview 20 practitioners and researchers who use AI coding tools to enrich and validate the obtained catalog of quality issues. From these analyses, we derive a taxonomy of 87 types of developer-attributed quality issues in AI-generated code, going beyond functional bugs. Our findings contribute an empirically grounded taxonomy and implications for the design and evaluation of AI coding assistants and agents.
